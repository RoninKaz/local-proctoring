   # Smart Proctoring

   Система контроля экзамена по камере: обнаружение телефона, направления взгляда и блокировка клавиш.

   ## Запуск
   1. Установить зависимости: pip install -r requirements.txt
   2. Запустить: python main.py

   ## Управление
   - g: включить/выключить защиту среды
   - q: выход
